# 📘 Assignment: Games in Python

## 🎯 Objective

Build a simple text-based game in Python that uses loops, conditionals, and user input to create an engaging interactive experience.

## 📝 Tasks

### 🛠️ Build the Game Setup

#### Description
Create a basic Python game where the player interacts with the program through text input and sees progress updates on the screen.

#### Requirements
Completed program should:

- Define a list of words or choices for the game
- Choose a random item from the list
- Display a placeholder for each letter or choice so the player can track progress
- Print clear instructions at the start of the game

### 🛠️ Implement Player Guessing

#### Description
Add the core gameplay loop that asks the player to make guesses and updates the game state after each turn.

#### Requirements
Completed program should:

- Ask the user to enter a letter or guess
- Check whether the guess is correct
- Update the visible word or game board after each valid guess
- Keep track of remaining attempts or lives
- Reject invalid input such as empty entries or repeated guesses

### 🛠️ Finish the Game Flow

#### Description
Add the end-of-game logic so the player receives feedback and the program clearly announces whether they won or lost.

#### Requirements
Completed program should:

- End the game when the player correctly guesses the word or runs out of attempts
- Display a final win or loss message
- Show the correct answer at the end of the game
- Allow the player to play again if desired
